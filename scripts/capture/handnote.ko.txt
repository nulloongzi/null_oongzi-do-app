# scripts/capture/handnote.ko.txt — 손글씨 주석 카드뉴스(인스타 3:4, 1080x1440) 정의.
#
# 한 편 = 기능 하나. 'post' 줄로 편을 시작하고, 그 아래 줄이 순서대로 한 장씩.
# 필드는 '|' 로 가른다. 문구 안 줄바꿈은 \n, 형광펜 칠할 말은 [대괄호].
#
#   post |<편 id>                                 → cards/handnote/<편 id>/01.png …
#   cover|<화면>|<y0>|<빨간 머리말>|<큰 제목>|<곁말>|<표시>
#   step |<화면>|<y0>|<제목>|<파란 설명(최대 2줄)>|<표시>
#
# 화면 — 실제 캡처에서 가져온다(폭 1080 으로 맞춘 뒤 좌표를 잰다).
#   still:<이름>          marketing-assets/stills/<이름>.png
#   <흐름>@<비트>[+초]    reels/flows/<흐름>_ko.mp4 의 CAPTURE_BEAT(+SETTLE) 프레임
#   <흐름>@<초>           절대 시각
# y0 — 화면에서 카드(972x900, 좌우 54~1026)로 보여줄 부분의 위쪽 끝(원본 y).
#
# 표시 — ';' 로 여러 개. 좌표는 전부 원본(폭 1080) 기준.
#   circle x y w h [여백]   누를 곳에 빨간 동그라미
#   word <말> x y           빨간 붓글씨 한마디 + 바로 앞 동그라미로 화살표
#
# 규칙(시안 v2): 제목 검정 펜글씨 · 설명 파랑 · 강조 빨강 · 형광펜 노랑, 한 장에 3색까지.
# 손글씨는 앱 글자를 덮지 않는다. 설명은 카드 위 설명 줄에만, 카드 안엔 동그라미·한마디만.
