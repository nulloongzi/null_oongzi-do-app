# 인스타 카드뉴스 스크립트 — 코치마크/스포트라이트 스타일
#
# 형식: <세트>|<종류>|<출처>|<한글1>|<한글2>|<영문>|<스팟>|<포커스>
#   cover / end = 브랜드 크림 카드(표지·마무리). 출처·스팟·포커스 비운다.
#   step = 실제 화면 풀블리드 + 딤 + 캡션. 출처는 <흐름>@<비트>[+추가대기].
#     스팟 = "x,y,r" (0~1 화면상대 좌표 + 반지름px). 이 칸이 있으면 그 지점만
#            밝게 남기고 나머지를 어둡게(누를 버튼 강조). 비우면(-) 전체를
#            살짝만 딤(지도·결과처럼 화면 전체가 콘텐츠인 카드).
#     포커스 = 세로 어디를 카드 중앙에 둘지(0=맨 위, 1=맨 아래).
#   한글2를 비우면 한 줄. 스팟 카드 문구는 명령형으로.
