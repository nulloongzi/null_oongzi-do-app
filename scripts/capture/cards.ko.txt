# 인스타 카드뉴스 스크립트 (한글 + 영문 병기)
#
# 형식: <세트>|<종류>|<출처>|<한글 윗줄>|<한글 아랫줄>|<영문>
#   cover = 표지. 출처 칸은 비운다.
#   step  = 화면 + 문구. 출처는 <흐름>@<비트>[+<추가대기>][:<위>-<아래>] —
#           reels/flows/<흐름>_ko.mp4 에서 그 시각의 프레임을 뽑는다.
#           흐름 녹화본은 자막이 없는 판이라 카드 문구와 겹치지 않는다.
#           뒤에 구간을 붙이면 화면 세로에서 그 띠만 잘라 크게 키운다
#           (0=화면 맨 위, 1=맨 아래). 카드뉴스는 폰에서 읽히는 게 전부라,
#           바텀시트가 주인공인 화면을 폰 통째로 넣으면 글씨가 손톱만 해진다.
#           지도처럼 전체가 그림인 화면은 구간을 비워 폰째로 둔다.
#           +추가대기: 네트워크로 받아오는 그림(릴스 커버)은 비트 직후엔
#           아직 회색이라 더 기다렸다 뽑는다.
#   end   = 마지막 브랜드 카드. 출처 칸은 비운다.
#
# 한글 아랫줄을 비우면 윗줄이 큰 글씨 한 줄로 나온다.
# 문구는 릴스(reels.ko.txt)와 같은 말을 쓴다 — 같은 계정에서 두 형식이
# 따로 노는 것처럼 보이면 안 된다.
