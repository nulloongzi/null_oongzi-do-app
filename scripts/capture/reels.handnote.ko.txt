# 사용법 릴스 (make_reels.py) — 카드 한 편 = 릴스 한 편. 문구·동그라미 좌표는 handnote.ko.txt 의
# 같은 편(post)에서 가져온다. 여기에는 녹화본의 '어느 구간을 어떤 창으로' 보일지만 적는다.
#
#   reel | <편 id>                               이 편 시작(흐름 녹화본 = <편 id>_<lang>.mp4)
#   hook | <초> | <창 y0>                        첫 장면 — 표지 제목 + 결과 화면 정지컷
#   seg  | <단계> | <시작초> | <끝초> | <창 y0> | <동그라미 켜는 초>-<끄는 초>(없으면 비움)
#   outro| <다음 편 한 줄>                        끝 카드
#
# 시각은 녹화본 기준(2026-10-07 촬영). 창은 폭 1080 의 화면에서 y0 부터 1578px(카드 창 972x1420
# 에 0.9배로 들어가는 높이)을 보인다. 화면 높이 2460 이라 y0 은 0~882.
# 장면 길이는 음악 박자(Tong tong 가야금, 129 BPM → 한 박 0.465초)의 배수로 맞춘다 —
# 컷이 박자에 떨어진다. 4박 1.86 · 6박 2.79 · 7박 3.26 · 8박 3.72.
# 동그라미는 '누르기 전에' 그려지고, 누르는 순간 꺼진다.

reel|urgent
hook|23.0|882
seg|1|6.90|9.69|882|7.15-8.85
seg|2|9.60|12.39|882|9.85-12.39
seg|3|12.40|15.66|882|12.60-14.40
seg|4|16.40|18.26|120|
seg|4|22.00|23.86|882|22.15-23.86
seg|5|26.00|29.72|882|26.25-28.25
outro|다음 편: 새 회원은 식구 모집으로 🍚
