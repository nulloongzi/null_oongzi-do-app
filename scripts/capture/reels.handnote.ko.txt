# 사용법 릴스 (make_reels.py) — 카드 한 편 = 릴스 한 편. 문구·동그라미 좌표는 handnote.ko.txt 의
# 같은 편(post)에서 가져온다. 여기에는 녹화본의 '어느 구간을 어떤 창으로' 보일지만 적는다.
#
#   reel | <편 id>                               이 편 시작(흐름 녹화본 = <편 id>_<lang>.mp4)
#   hook | <초 또는 shot:이름> | <창 y0> | <흐름(선택)>   첫 장면 — 표지 제목 + 결과 화면 정지컷
#   seg  | <단계> | <시작초> | <끝초> | <창 y0> | <동그라미 켜는 초>-<끄는 초> | <출처> | <동그라미>
#     출처(선택)   비우면 이 편 흐름. 다른 흐름 이름(예: collect), 또는 shot:<card-shots 이름>
#                  (그 고정 화면을 시작~끝 길이만큼 세운다 — 녹화에 없는 장면용)
#     동그라미(선택) 비우면 카드의 것('스틸'에서 잰 좌표면 상태 바만큼 자동으로 올린다).
#                  '-' 은 없음, 'x y w h [pad]' 는 흐름 좌표로 직접(여러 개는 ; 로)
#   outro| <다음 편 한 줄>                        끝 카드
#
# 시각은 녹화본 기준(2026-10-07 촬영). 화면은 가로 꽉 차게 1:1 로, 맨 위 종이 띠(290px, 제목 한
# 줄) 아래에 화면 y0 부터 1630px 을 보인다. 좌표는 흐름본·카드와 같다(상태 바를 덜어낸 폭 1080).
# 원본(reels/raw)은 아래 제스처 바까지 있어 높이 2520 → y0 0~890. y0 을 크게 주면 화면
# 맨 아래에 맞춘다(시트 버튼 아래 여백까지 보여 '잘린' 느낌이 없다). 아래쪽 300px 쯤은 인스타
# 글·계정 이름이 덮으니, 동그라미 칠 곳이 그 위에 오도록 고른다.
# 장면 길이는 음악 박자(Tong tong 가야금, 129 BPM → 한 박 0.465초)의 배수로 맞춘다 —
# 컷이 박자에 떨어진다. 4박 1.86 · 6박 2.79 · 7박 3.26 · 8박 3.72.
# 동그라미는 '누르기 전에' 그려지고, 누르는 순간 꺼진다.
