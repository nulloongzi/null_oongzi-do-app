# 형식: <흐름>|<종류>|<앵커>|<윗줄>|<아랫줄>
#   hook  = 도입 1.6초, 영상 위 큰 글씨. 앵커 칸은 비운다.
#   cap   = 본문 자막. 앵커는 앱이 남기는 CAPTURE_BEAT 이름이다
#           (map/filter/result/detail/saved/lunchbox/profile/namecard/share).
#           앱이 그 화면을 띄우는 순간에 정확히 붙고, 다음 비트에서 사라진다.
#   outro = 마지막 브랜드 카드. 앵커 칸은 비운다.
# 아랫줄을 비우면 한 줄짜리 자막이 된다.
#
# 비트가 수거되지 않은 경우(구버전 앱으로 찍은 녹화본)에는 장면 전환 감지 →
