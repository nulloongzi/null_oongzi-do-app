# 릴스 자막 스크립트 (한글 + 영문 병기, 나레이션은 한국어)
#
# 형식: <흐름>|<종류>|<앵커>|<한글 윗줄>|<한글 아랫줄>|<영문>|<나레이션(선택)>
#   hook  = 도입 1.6초, 영상 위 큰 글씨. 앵커 칸은 비운다.
#   cap   = 본문 자막. 앵커는 앱이 남기는 CAPTURE_BEAT 이름이다
#           (map/filter/result/detail/saved/lunchbox/diet/profile/namecard/share).
#           앱이 그 화면을 띄우는 순간에 붙고 다음 비트에서 사라진다.
#   outro = 마지막 브랜드 카드. 앵커 칸은 비운다.
#
# 한글 아랫줄을 비우면 윗줄이 큰 글씨 한 줄로 나온다.
# 영문은 한글 아래 작은 글씨로 함께 나온다(같은 영상 안에 병기).
# **나레이션(TTS)은 한국어만 읽는다** — 영문은 자막 전용이다.
# 마지막 칸을 채우면 화면 문구 대신 그것을 읽는다. 화면은 짧고 굵게, 음성은
