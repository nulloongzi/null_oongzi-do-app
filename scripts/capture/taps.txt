# 탭 표시 좌표 — 후처리로 "여기를 눌렀다" 물결을 그릴 지점.
#
# 형식: <흐름>|<앵커>|<x>|<y>|<리드(초, 선택)>
#   앵커 = 자막과 같은 CAPTURE_BEAT 이름.
#   x, y = 0~1, **기기 화면 전체** 기준 비율(상태바 포함). 해상도와 무관하다.
#   리드 = 비트보다 몇 초 앞에 누르는가. 비우면 TAP_LEAD(기본 0.5).
#
# 값은 지어낸 게 아니라 캡처한 스틸에 격자를 얹어 잰 것이다.
#
# ── 여기 없는 지점은 일부러 뺀 것이다 ────────────────────────
# 합성해서 프레임을 확인해보니 아래 셋은 고정 좌표로 못 맞춘다:
#   · 지도 마커 — 탭 시점엔 아직 이전 화면(필터 결과)이라 마커 위치가
#     데이터에 따라 달라진다. 빈 지도 한복판에 물결이 떴다.
#   · 상세의 🍱 — 급구 배너가 있는 팀은 아이콘 줄이 아래로 밀린다.
#   · 식단표 버튼 — 찜한 팀 수에 따라 시트가 늘고 줄어 버튼이 움직인다.
#   · 도시락 FAB — 상세가 닫히고 시트가 뜨기까지 지도가 드러나는 창이
#     0.5초뿐이라 누를 자리가 화면에 없다.
# 위치가 고정돼 있고 충분히 오래 보이는 것만 남긴다.

# ① 찾기
discover|filter|0.870|0.078        # 검색바 오른쪽 필터 아이콘
discover|result|0.653|0.955|1.1    # 필터 시트의 '적용하기'
                                   # 시트가 비트보다 0.5초 먼저 닫힌다

# ③ 자랑하기
share|namecard|0.630|0.578|1.2     # 프로필 카드의 '포장하기'
                                   # 카드가 비트보다 0.9초 먼저 닫혀 리드를 늘렸다
share|profile|0.105|0.925          # 왼쪽 아래 밥이름 버튼
share|share|0.800|0.857            # 상세 하단의 '공유'
