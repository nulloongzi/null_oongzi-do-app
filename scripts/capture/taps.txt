# 탭 표시 좌표 — 후처리로 "여기를 눌렀다" 물결을 그릴 지점.
#
# 형식: <흐름>|<앵커>|<x>|<y>
#   앵커 = 자막과 같은 CAPTURE_BEAT 이름. 그 화면이 나타나기 직전에 물결이 뜬다.
#   x, y = 0~1, **기기 화면 전체** 기준 비율(상태바 포함). 해상도와 무관하다.
#
# 값은 지어낸 게 아니라 캡처한 스틸(marketing-assets/stills/)에서 잰 것이다.
#
# 지도 마커에는 표시하지 않는다. 탭은 화면이 바뀌기 0.5초 전에 일어나는데 그때
# 지도는 아직 이전 화면(필터 결과)이라 마커가 어디 있을지 데이터에 따라 달라진다
# — 실제로 빈 지도 한복판에 물결이 떴다. 위치가 고정된 UI 버튼만 표시한다.
# 앱 UI 에서 버튼 위치가 바뀌면 여기도 다시 재야 한다 — 스틸에 격자를 얹어
# 읽으면 된다. 해당 줄을 지우면 그 지점에는 물결이 안 그려진다.

# ① 찾기
discover|filter|0.870|0.078     # 검색바 오른쪽 필터 아이콘
discover|result|0.653|0.955     # 필터 시트의 '적용하기'

# ② 담고 관리
save|saved|0.936|0.657          # 상세 헤더의 🍱
save|lunchbox|0.105|0.845       # 왼쪽 아래 도시락 버튼
save|diet|0.490|0.670           # '식단표 (스케줄 확인)'

# ③ 자랑하기
share|profile|0.105|0.925       # 왼쪽 아래 밥이름 버튼
share|namecard|0.639|0.580      # 프로필 카드의 '포장하기'
share|share|0.800|0.857         # 상세 하단의 '공유'
