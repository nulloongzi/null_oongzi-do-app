# 누룽지도 모션 정의서 → 웹 저장소로

**원본은 하나다: 웹 저장소 [`docs/motion-spec.md`](https://github.com/nulloongzi/null_oongzi-do/blob/main/docs/motion-spec.md).**
웹앱과 이 앱의 모션(시트·팝업·눌림·지도 카메라 등)을 한 문서에서 나란히 적었다. 이 파일은 안내만 둔다.

- 모션을 바꾸면 원본 §2(모션 이름표)·§3(기능별 모션 표)와 부록 B(이 앱의 값·코드 위치)를 같이 고친다.
- 원하는 모션은 이름으로 부른다. 예: "필터 시트를 M05 가운데 팝업 스프링으로".

| 절 | 내용 |
|---|---|
| §1 | 곡선 별명(감속·튕김·등속 …) |
| §2 | 모션 이름표 M00–M23 — 웹 값 · 앱 값 |
| §3 | 기능별 모션 표(지도·필터·상세·🍚·픽업·도시락·내 카드·로그인/폼) |
| §4 | 맞지 않는 곳 · 고칠 후보 · 코드상 버그 |
| 부록 B | 이 앱의 모션 값과 코드 위치(패턴 번호 `F`) |
