# 누룽지도 UI/UX 정의서 → 웹 저장소로

**원본은 하나다: 웹 저장소 [`docs/ui-ux-spec.md`](https://github.com/nulloongzi/null_oongzi-do/blob/main/docs/ui-ux-spec.md).**
웹앱과 이 앱의 화면을 한 문서에서 나란히 적었다. 이 파일은 안내만 둔다(`docs/design-system.md` 와 같은 방식).

- 화면을 바꾸면 원본의 해당 장을 같이 고친다. 웹과 다르게 만들었으면 원본 §26 표에 줄을 더한다.
- 기능이 양쪽에 있는지는 이 저장소 `docs/feature-parity.md`, 모양이 같은지는 웹 저장소 `docs/visual-parity.md`.
